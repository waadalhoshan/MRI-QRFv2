# 10. Output files and result schema

This document maps the study stages to the files that should be preserved in the public replication archive.

## Classical ML — per resolution

The classical runner produces model-specific output under the configured result root (`ML_32`, `ML_64`, or `ML_128`).

Preserve:
- trained `.joblib` models
- validation metrics
- clean-test metrics
- 15 corrupted-condition metrics
- per-class metrics
- confusion matrices
- raw per-slice predictions
- ARR tables
- DRI tables
- CD-DRI tables
- across-seed summaries
- patient-clustered bootstrap outputs if generated by the classical runner

Key summary filenames used during the study include:
- `condition_summary_across_seeds.csv`
- `DRI_summary_across_seeds.csv`

## Classical subject-level analysis

Preserve the entire `subject_level_analysis` output directory.

Important files:
- `subject_level_all_predictions.csv`
- `subject_level_per_class_metrics.csv`
- `subject_level_condition_results.csv`
- `subject_level_clean_results.csv`
- `subject_level_ARR.csv`
- `subject_level_DRI.csv`
- `subject_level_CD_DRI.csv`
- `subject_level_clean_summary_across_seeds.csv`
- `subject_level_DRI_summary_across_seeds.csv`
- `subject_level_CD_DRI_summary_across_seeds.csv`
- `subject_level_resolution_comparison.csv`
- `subject_level_condition_summary_across_seeds.csv`
- `subject_level_ARR_summary_across_seeds.csv`
- confusion matrices

## Deep learning

The RunPod script writes under:

```text
results/DL_128/
  <dataset>/
    <model>/
      seed_<seed>/
```

Per-run files include:
- `best_model.pt`
- `config.json`
- `training_history.csv`
- slice-level metrics/predictions
- subject-level metrics/predictions
- per-class metrics
- confusion matrices
- run summary

Combined files include:
- `run_summaries.csv`
- `metrics_all_runs_slice_level.csv`
- `metrics_all_runs_subject_level.csv`
- `predictions_all_runs_slice_level.csv`
- `predictions_all_runs_subject_level.csv`
- `condition_summary_across_seeds_slice_level.csv`
- `condition_summary_across_seeds_subject_level.csv`
- `DRI_by_dataset_model_seed_slice.csv`
- `DRI_by_dataset_model_seed_subject.csv`
- `CD_DRI_by_model_seed_slice.csv`
- `CD_DRI_by_model_seed_subject.csv`
- `DRI_summary_across_seeds_slice.csv`
- `DRI_summary_across_seeds_subject.csv`
- `CD_DRI_summary_across_seeds_slice.csv`
- `CD_DRI_summary_across_seeds_subject.csv`

## Statistical outputs

Recommended:
```text
results/statistics/
  glmm_input.csv
  glmm_fixed_effects.csv
  glmm_clean_vs_corrupted_holm.csv
  <dataset>__<model>__glmer.rds
  <dataset>__<model>__summary.txt
  patient_clustered_bootstrap_CIs.csv
```

## Reader study

Recommended public outputs:
```text
results/reader_study/
  anonymized_ratings.csv
  inter_rater_agreement.csv
  readability_by_severity.csv
  readability_by_distortion.csv
```

Do not publish the private answer key.

## Figures

Recommended:
- main ARR heatmap(s)
- DRI/CD-DRI figure(s)
- reader-study rating distribution figure(s)
- appendix classical resolution ARR heatmaps

Keep source tables used to generate every figure.
