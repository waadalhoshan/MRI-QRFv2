# Data directory

This tree is intentionally empty in the public replication package.

Do not commit OASIS MRI files or derived MRI images.

Suggested local mapping:
```text
data/
  raw/
  organized/
  split/
  clean_128/
  clean_64/
  clean_32/
  distortions_128/
  distortions_64/
  distortions_32/
  manifests/
```

Non-image cohort/split manifests can be published here if allowed and if they do not contain restricted information.
